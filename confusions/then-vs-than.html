Word confusion

Then vs Than

Quick answer

Then is about time or what happens next (“first this, then that”). Than is used to compare two things (“better than,” “more than”).

Then: time, sequence, or consequence

Use then to show when something happens or what comes next in a sequence.

✓ We had dinner, then watched a movie.
✕ We had dinner, than watched a movie.
✓ If it rains, then we'll stay inside.
✕ If it rains, than we'll stay inside.

Than: comparisons

Use than only when you are comparing two or more things.

✓ This book is better than the last one.
✕ This book is better then the last one.
✓ She runs faster than I do.
✕ She runs faster then I do.

Side by side

If no comparison is happening, you almost certainly want then. If two things are being weighed against each other, you want than.

Memory trick

Than has an “a”, like “compArison.” Then has an “e”, like “sequEnce” or “timE”.

AffectvsEffect

Affect is (almost always) a verb meaning “to influence.” Effect is (almost always) a noun meaning “a result.” If you can swap in “influence,” use affect. If you can swap in “a result,” use effect.
